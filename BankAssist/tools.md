verify_identity: Input `customer_id` (str), `pin` (str). Reads the customer's stored PIN, failure counter and lock flag. Returns `{"verified": true}` on success (and resets the failure counter); otherwise `{"verified": false, "reason": "unknown_customer" | "wrong_pin" | "locked"}`, plus `attempts_left` (int) for a wrong PIN. The 3rd consecutive failure locks the profile. Implemented in `src/bankassist/bank.py` (`Bank.verify_identity`).
issue_session: Input `customer_id` (str). Creates a session bound to that customer. Returns `{"session_token": str, "customer_id": str, "expires_in_s": 900}`.
resolve_session: Input `session_token` (str). Reads the session table. Returns `{"valid": true, "customer_id": str}` if the token exists and is under 15 minutes old, otherwise `{"valid": false}`.
list_accounts: Input `customer_id` (str). Reads the accounts table. Returns `{"customer_id": str, "accounts": [{"account_id": str, "type": "checking" | "savings"}]}` for every account owned by that customer.
get_balance: Input `account_id` (str). Reads one account. Returns `{"account_id": str, "type": str, "balance": float}` or `{"error": "no_such_account"}`.
get_transactions: Input `account_id` (str), `limit` (int, default 5). Reads the account's transaction list. Returns `{"account_id": str, "transactions": [{"date": "YYYY-MM-DD", "desc": str, "amount": float}]}` (most recent last, negative amounts are debits) or `{"error": "no_such_account"}`.
transfer_funds: Input `from_account` (str), `to_account` (str), `amount` (float), `approval_id` (str or null). Debits the source, credits the destination, appends a transaction to both, marks the approval as used and records the transfer. Returns `{"status": "completed", "transfer_id": str, "new_balance": float}` or `{"status": "failed", "reason": "no_such_account" | "invalid_amount" | "insufficient_funds"}`.
check_payee: Input `customer_id` (str), `to_account` (str). Reads the customer's saved-payee list. Returns `{"to_account": str, "known_payee": bool, "external": bool}`; `known_payee` is true for the customer's saved payees and own accounts, `external` is true for IDs starting with `EXT-`.
daily_transfer_total: Input `from_account` (str). Reads the transfer history. Returns `{"from_account": str, "total_last_24h": float}`, the sum of transfers out of that account in the last 24 hours.
approve_transfer: Input `from_account` (str), `to_account` (str), `amount` (float). Creates a single-use approval record. Returns `{"approval_id": str, "valid_for_s": 600}`.
record_audit: Input `agent` (str), `event` (str), `details` (dict). Appends an entry to the append-only audit log. Returns `{"logged": true, "seq": int}`.
parse_request: Input `text` (str, one customer message; a PIN in it is already masked). The mode ("rules" or "llm") is chosen from environment variables and recorded in the trace. Converts free text into a structured request. Returns `{"intent": "check_balance" | "view_transactions" | "transfer" | "confirm" | "decline" | "help" | "unknown", "account_id", "account_type", "from_account", "from_type", "to_account", "to_type", "amount", "skip_review"}` (unknown fields are null). In "rules" mode it uses keyword/regex matching (`rule_parse` in `src/bankassist/agents.py`); in "llm" mode it calls an OpenAI-compatible chat-completions endpoint configured by environment variables (`src/bankassist/llm.py`) and falls back to the rules on any error.
